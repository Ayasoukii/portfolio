Pipeline CI/CD avec Jenkins, Docker & MySQL

Du commit au déploiement : une chaîne automatisée qui construit, conteneurise et déploie une application Java à chaque modification.

Type
Projet académique
Domaine

Outils

Public sur GitHub

Objectif

Mettre en place un pipeline CI/CD complet pour une application Java Spring MVC packagée en WAR, en automatisant le build Maven, la dockerisation et le déploiement sur des machines virtuelles avec Docker Compose.

Architecture du pipeline

  1. GitHubWebhook et exécution périodique (cron)
  2. JenkinsCheckout du code
  3. MavenBuild et packaging WAR
  4. DockerCréation de l’image
  5. DéploiementDocker Compose sur VM Ubuntu : Tomcat + MySQL

Fonctionnalités mises en œuvre

  • CI/CD : pipeline Jenkins (checkout, build, image Docker, déploiement Docker Compose).
  • Déclenchements : webhook GitHub et exécution périodique (cron).
  • Base de données : MySQL, avec insertion automatique d’employés fictifs toutes les 30 secondes pour valider la chaîne.
  • Supervision : suivi des conteneurs avec docker stats.
